# Professor Doubt Tracker — PWA version

This version is configured as a Progressive Web App (PWA) for Android/Chrome.

## Upload to GitHub
Replace the files in your existing repository with **all files and the `icons` folder** from this package.

## GitHub Pages
Use:
**Settings → Pages → Deploy from a branch → main → /(root)**

Open the HTTPS GitHub Pages URL.

## Installing on Android
After opening the live site:
1. Wait a few seconds and refresh once if necessary.
2. If supported, the green **📲 Install App** button will appear.
3. Tap it and choose **Install**.
4. If the browser doesn't provide the automatic prompt, open Chrome's ⋮ menu and choose **Install app** or **Add to Home screen**.

## Important
Do not open `index.html` directly from your phone's file manager. Installation requires the live HTTPS site.

Your doubts are stored locally on the device/browser. GitHub Pages hosts the application; it does not sync the data between different devices.
